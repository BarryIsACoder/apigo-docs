    Model Selection Guide¶

    ​ 按使用场景选择模型¶

    编程开发编程开发¶

    • 首选：GPT-5.2、GPT-5.1-Codex-High、Claude Opus 4.5、Qwen3-Coder-480B
    • 备选：Claude Sonnet 4.5、DeepSeek V3.1、Gemini 3 Pro、o4-mini
    • 经济型：GPT-5.1-Codex-Mini、DeepSeek V3.2 Exp、Qwen3-Coder-Plus

    文本创作文本创作¶

    • 首选：GPT-5.2、GPT-5.1、Claude Opus 4.5
    • 备选：Claude Sonnet 4.5、Gemini 3 Pro、Claude 4.1 Opus
    • 中文优化：QwQ Plus、Kimi K2 正式版、Qwen Max

    复杂推理复杂推理¶

    • 首选：GPT-5.2-Thinking、o3-pro、Claude Opus 4.5 Thinking
    • 备选：QwQ Plus、Gemini 3 Pro Thinking、Claude Sonnet 4.5 Thinking
    • 轻量级：o4-mini、DeepSeek R1-0528、QwQ 32B

    快速响应快速响应¶

    • 首选：Gemini 3 Flash、GPT-5.1-Mini、Grok 4 Fast
    • 备选：Claude Haiku 4.5、Gemini 2.5 Flash、GPT-4.1-Nano
    • 经济型：GPT-3.5 Turbo、Grok 3 Mini Fast

    图像生成图像生成¶

    • 顶级质量：GPT-Image-1.5、Flux Kontext Max
    • 平衡选择：Gemini 3 Pro Image、DALL·E 3、Flux Kontext Pro
    • 性价比：GPT-Image-1-Mini、Sora Image、GPT-4o Image
    • 国产选择：SeeKDream 4.5

    视频生成视频生成¶

    • 专业级：Veo 3.1、Sora 2 Pro
    • 特殊需求：Sora 2 Character（角色动画）、Veo 3.1 FL（帧级别控制）
    • 快速版：Veo 3.1 Fast、Sora Video 2 (15s)
    • 国产选择：SeeKDream 4.5、SeeKDream 4.0

    长文本处理长文本处理¶

    • 首选：Gemini 3 Pro（2M上下文）、Gemini 2.5 Pro（2M）
    • 高质量：Claude Opus 4.5（200K）、GPT-5.2（128K）
    • 备选：Kimi K2（200K）、Gemini 1.5 Pro（2M）

    联网搜索联网搜索¶

    • 深度搜索：Grok 3 DeepSearch（按次计费）

    多模态理解多模态理解 ️¶

    • 图文理解：Doubao 1.5 Vision Pro、GPT-4o、Gemini 3 Pro
    • 视觉问答：Claude Opus 4.5、Gemini 3 Pro Image

    ​ 成本优化建议¶

    1. 分级使用：简单任务用便宜模型，复杂任务用高级模型
    2. 测试优化：先用小模型测试，确定需求后再用大模型
    3. 批量处理：大量相似任务可以选择 Nano 或 Mini 版本
    4. 缓存复用：对重复查询结果进行缓存
