## **快速响应**快速响应

## **联网搜索**联网搜索

## **多模态理解**多模态理解 ️

- 图文理解：Doubao 1.5 Vision Pro、GPT-4o、Gemini 3 Pro
- 视觉问答：Claude Opus 4.5、Gemini 3 Pro Image

### ​ 成本优化建议

1. **分级使用**：简单任务用便宜模型，复杂任务用高级模型
2. **测试优化**：先用小模型测试，确定需求后再用大模型
3. **批量处理**：大量相似任务可以选择 Nano 或 Mini 版本
4. **缓存复用**：对重复查询结果进行缓存
